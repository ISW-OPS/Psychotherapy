21. Catatan & Soalan Terbuka

Soalan kepada Pengurusan (Pending Decision):
  • NLC class — platform mana? (GHL / Google Meet / Zoom)
  • Mekanisme integrasi penuh GHL ↔ Psychotherapy supaya closer tak buka banyak sistem?
  • Format resit / invoice final untuk accounting documentation
  • Sumber FAQ lengkap (dari Syafa)
  • WhatsApp Business API provider — WATI / 360dialog / lain?
  • Budget untuk AI integration (OpenAI / Claude)
  • Multi-branch atau single-branch ISW?
Risiko Utama yang Perlu Dimitigate:
  • R1 — GHL API access delay: Sprint 2 boleh tertangguh kalau GHL API tak ready. Mitigasi: fallback manual entry.
  • R3 — WhatsApp API rate limit: Pilih provider rasmi + throttling logic.
  • R4 — PDPA medical records & DNA: Encryption + audit log + consent digital.
  • R8 — Scope creep Phase 1: Freeze scope selepas Sprint 1, lock 5 priority utama.
