🩺 KOB DONE

Admin setup slot di kob-slots.html (template hari + jam + max)
  ↓
Patient signup → auto buka kob.html stage='kyc'
  ↓
Patient isi KYC:
  • IC, alamat, waris, masalah kesihatan
  • Upload IC + dokumen
  • Consent + tick "bukan wakil"
  → INSERT psy_kyc_submissions + psy_patients
  → kob_status='kyc_done'
  ↓
Patient tempah slot KOB:
  • Pilih mod (F2F/Online), tarikh, slot
  • Auto-block Isnin/Selasa + cuti klinik
  → INSERT psy_kob_sessions (status='booked')
  → kob_status='booked'
  ↓
Doctor di kob-detail.html klik "Hadir":
  → status='hadir'
  → kob_status='hadir'
  ↓
Doctor isi:
  • Questionnaire (anak, tidur, gaya hidup)
  • Vitals (BP, BMI, HR) → INSERT psy_vitals
  • SOAP notes → INSERT psy_soap_notes (patient tak nampak)
  ↓
Doctor cadang pakej:
  → UPDATE recommended_package_id, price
  → kob_status='package_recommended'
  ↓
Patient bayar via payment.html:
  → INSERT psy_payments
  → UPDATE package_payment_status='paid'
  → kob_status='package_paid'
  ↓
Patient sign agreement:
  • Baca clauses dari pakej
  • Lukis signature → generate PDF
  → INSERT psy_kob_agreements
  ⛔ Berhenti — tunggu doctor
  ↓
Doctor klik "Tandakan Selesai":
  🔥 UPDATE patient kob_status='completed'
  🔥 Set active_package_id, package_expires_at
  🔥 INSERT psy_package_purchases
  🔥 AUTO-CIPTA psy_treatment_plans
     (goals + coaching_schedule dari pakej)
  ↓
Patient auto-redirect ke plan.html (setup 24 sesi)

💊 Treatment Plan DONE

  ↓

  → schedule_setup_at IS NULL → tunjuk WIZARD
  ↓

  • Pasangan hari: Jum+Sab atau Sab+Ahd
  • Jam hari 1 + jam hari 2
  • Preview 3 minggu pertama
  ↓
Klik "Sahkan & Auto-Jadual 24 Sesi":
  → UPDATE plan: preferred_pair, schedule_setup_at
  🔥 generateScheduleDates(): 12 minggu × 2 sesi
  🔥 INSERT 24 row psy_plan_weekly_progress
     (status='booked', skip tarikh cuti)
  ↓
Progress Mingguan tunjuk 12 minggu:
  • Setiap kad: tarikh + masa + status + Reschedule
  ↓
Coach edit per minggu via plan-week.html:
  • Status (Hadir/Reschedule/Tidak Hadir)
  • Nota minggu
  • Score (0-10)
  • Kepatuhan rawatan (madu/nafas/bumi/dll)
  • Coaching checklist
  → UPDATE psy_plan_weekly_progress
  → UPDATE psy_plan_compliance
  ↓
Hadir → 🔥 Auto-deduct supplies dari inventory
  ↓
Patient MISS sesi (tarikh lepas, status booked):
  🔥 autoMarkMissedAndExtend():
     • Tanda 'cancel'
     • Cipta extension week (2 sesi)
     • status='extension_pending_payment'
     • extension_price dari pakej
     • Notify patient
  ↓
Patient bayar extension:
  → status='extension_paid' → boleh tempah tarikh baru
  ↓
package_expires_at lepas:
  🔥 fn_complete_expired_treatments()
  → plan status='completed'
  → patient outcome_status='completed'
  → Notify feedback

🔄 Auto-PO Inventory CONCEPT

💡 Schema dah ada (auto_reorder_enabled,
   last_auto_po_at). Cron / trigger belum implement.

🔄 CONCEPT FLOW:

Setup (Admin):
  • Buka inventory.html → item edit
  • Toggle auto_reorder_enabled=true
  • Set max_qty + auto_reorder_qty
  • Set supplier_info (name, cost, lead_days)
  ↓
🔥 System cron daily (1:00 AM):
   SELECT psy_inventory_items WHERE
     qty_in_stock <= max_qty * 0.3
     AND auto_reorder_enabled = true
     AND (last_auto_po_at IS NULL
          OR last_auto_po_at < now() - 7 days)
  ↓
Untuk setiap item match:
  → INSERT psy_inventory_requests (
      is_auto_generated=true,
      qty_requested=auto_reorder_qty,
      status='pending_approval'
    )
  → UPDATE last_auto_po_at = now()
  → Notify Manager + Finance
  ↓
Manager review request:
  • Tengok cost estimation
  • Approve / Reject
  ↓
Bila approved:
  • Send PO ke supplier (manual / email)
  • Track delivery
  ↓
Bila barang sampai:
  • UPDATE psy_inventory_requests.status='purchased'
  • Adjust qty_in_stock
